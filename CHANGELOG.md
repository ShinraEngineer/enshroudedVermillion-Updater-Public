# EnshroudedVermillion changelog

## EnshroudedVermillion 1: first release

First release. Deploys scook's exact modded Enshrouded client 1:1 (ShroudForge, DualSense support, co-op auto-loot, cosmetics; server-side auto-doors run on the dedicated server), installs the resident launcher + silent tray updater, trusts the Shinra CC publisher, and locks the Steam build so updates do not overwrite the mods. Signed by Shinra CC.
